# Тесты cant.chat

Локальная имитация сервера Cloudflare и сквозные тесты в настоящем браузере
(два собеседника, фейковые камера и микрофон). Для работы сайта тесты не нужны
и в деплой не попадают (раздаются только файлы из `public/`).

```bash
npm i -D playwright ws && npx playwright install chromium
LOG=1 TEST_DROP=1 node tests/devserver.cjs &   # сервер на http://localhost:8788
node tests/e2e.cjs            # чат, сверка, ответ, удаление, P2P, файлы, вспышка, голосовые, два звонка, обрыв сети, запасной путь, третий лишний, хозяин пропал, сжечь
node tests/reconnect.cjs      # перезапуск сервера посреди разговора
node tests/code.cjs           # код комнаты: слабые коды, чужой код, вход в другом регистре, одноразовость
node tests/note.cjs           # записка: запечатать с фото, открыть по коду, второй раз нет, срок, сжечь (нужен TEST_DROP=1)
RATE_LIMIT=12 node tests/server.cjs   # правила сервера: токены, ICE только вдвоём, /ice закрыт, лимит частоты
node tests/hideip.cjs         # режим «скрыть IP» (сам поднимает сервер на 8789)
node tests/pages.cjs          # статические страницы: ссылки, три языка (EN/SV/RU) на страницах и в интерфейсе, переключатель по кругу, метка «Byggt i Sverige»
```

Переменные:
- `LOG=1` — писать пересылаемые кадры в `tests/relay.log` (e2e проверяет, что в них нет открытого текста).
- `TEST_DROP=1` — включить тестовый эндпоинт `/__drop`, которым e2e «обрывает сеть» хозяину на стороне сервера.
- `FAKE_TURN=1` — сервер притворяется, что TURN настроен (чтобы посмотреть пункт «Скрыть мой IP» включённым).
- `RATE_LIMIT=N` — лимит подключений в минуту с одного адреса (по умолчанию 30, как в `wrangler.toml`); `server.cjs` проверяет лимит, если переменная задана и у него, и у сервера.
- `SHOTS=путь` — сохранить скриншоты всех экранов в папку.
- `CHROME_PATH=…` — свой Chrome вместо Chromium из Playwright.

`devserver.cjs` повторяет логику `src/worker.js`: если меняешь сервер, меняй и его.
